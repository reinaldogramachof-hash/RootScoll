# Architecture Decision Records (ADR)

Este diretório armazenará os Architecture Decision Records (ADRs) do projeto.

## O que é um ADR

Um ADR é um documento curto que registra uma decisão arquitetural significativa, incluindo:

- o contexto que motivou a decisão;
- a decisão tomada;
- as alternativas consideradas;
- as consequências (positivas e negativas) da decisão.

## Convenção

- Um arquivo por decisão.
- Nomenclatura sugerida: `NNNN-titulo-curto-em-kebab-case.md` (ex.: `0001-uso-de-pnpm-workspaces.md`).
- ADRs não são retroativamente editados; decisões revisadas geram um novo ADR que referencia o anterior.
